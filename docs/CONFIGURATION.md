# 原生插件配置

入口：AstrBot → 插件 → **NekoNekoNin · P站搜图与画廊** → **配置**。本版不新增独立 Web 设置页。

以 AstrBot 4.29.1 的原生配置组件核对下拉标签、滑块、条件显示与高级折叠。配置键保持兼容；保存会重载插件，正在处理的请求应先完成。

| 配置键 | 界面名称 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `enabled` | 基础 · 启用插件 | true | 暂停后停止搜索、看图和发图；管理页设置仍可使用。 |
| `search_enabled` | 标签搜索 | true | 控制 pixiv_search 工具、搜索命令及管理页搜索。 |
| `user_enabled` | 画师作品 | true | 通过已确认的 UID 或作者主页查询最近作品。 |
| `view_enabled` | 查看与预览图片 | true | 控制 pixiv_view 和管理页预览，不影响独立发图开关。 |
| `send_enabled` | 向当前聊天发图 | true | 控制 pixiv_send 和发图命令，不接受任意群号或QQ号。 |
| `attach_guidance` | 基础 · 相关话题自动检索指导 | true | 仅相关消息添加搜图、作者、页码和来源说明。 |
| `default_count` | 结果 · 默认作品数 | 3 | 1–5；模型工具可按问题独立指定数量。 |
| `proxy_mode` | 网络 · 连接方式 | "system" | system 读取系统代理；direct 直连；custom 使用下方代理。 |
| `proxy_url` | 网络 · 自定义代理地址 | （留空） | 例如 http://127.0.0.1:7890；不支持用户名密码，不修改系统代理。 |
| `timeout_seconds` | 高级 · 单次操作总时限（秒） | 30 | 5–90秒；包含搜索详情和图片请求。 |
| `max_image_mb` | 图片 · 单张大小上限（MiB） | 4 | 1–8，默认与旧版一致为4；仅常规尺寸或动图静态预览。 |
| `exclude_ai` | 筛选 · 发现作品时排除 AI | true | 标签与画师列表默认排除 AI。指定 PID 仍检查全年龄分级并返回 AI 标记，不把这个开关当作指定作品的拦截器。 |
| `cache_ttl_seconds` | 高级 · 元数据缓存（秒） | 120 | 0–3600；0关闭缓存，图片不持久缓存。 |
| `cache_max_entries` | 高级 · 缓存条目上限 | 100 | 0–500；0关闭缓存。 |
| `max_concurrency` | 高级 · 网络并发数 | 3 | 1–6；较低并发可减少站点限流。 |
| `send_cooldown_seconds` | 发送 · 同一聊天发图冷却（秒） | 8 | 0–120；发送失败不计入冷却。 |
