# P站搜图与画廊

用自然语言搜索 Pixiv 插画，按收藏、点赞和浏览筛选，支持多页预览、当前会话发图与画廊管理。

版本：`1.1.3` · 许可：[MIT](LICENSE)

作者：**NekoNekoNin**。

## 能做什么

- 按关键词、画师 UID 或作品 PID 查询 Pixiv 作品，并提供原始来源。
- 读取真实点赞、收藏和浏览统计，可按最低门槛筛选并降序排列。
- 支持多页静态预览与当前聊天发图，已有画廊管理页面保留。

## 支持平台与标签

支持 QQ / OneBot v11（`aiocqhttp`，如 NapCat）与 AstrBot 内置 WebChat（`webchat`）。市场平台字段表示消息适配器；当前声明按已接入和验收范围填写，其他平台尚未验收。

标签：Pixiv、搜图、图片、画廊、人气筛选。

## 安装

在 AstrBot 的插件管理上传本插件发布 ZIP，或使用[本仓库地址](https://github.com/NekoNekoNin/astrbot_plugin_pixiv)安装。内部插件名保持 `astrbot_plugin_pixiv`，升级时沿用已有配置。元数据已绑定本仓库，更新时请核对版本与更新记录。

需要能访问 Pixiv 公共接口和图片 CDN。不需要 Pixiv 账号、Cookie 或 API Key。网络可选择直连、系统代理或自定义代理。

## 设置

入口：**AstrBot → 插件 → P站搜图与画廊 → 配置**。常用选项直接显示，适用时提供中文下拉标签、数值滑块、条件显示与高级折叠。完整选项见 [配置说明](docs/CONFIGURATION.md)。

## 聊天示例

- “找收藏超过 10000 的风景插画，优先收藏多的。”
- “查看这个画师 UID 的作品。”
- “把这个 PID 的第 2 页发出来。”

## 使用边界

仅处理全年龄作品；动图提供静态预览。人气排序基于返回中标明的候选取样，不能当作全站排名。发现作品默认排除 AI；指定 PID 的行为及 AI 标记见配置说明。网络拒绝和限流会如实返回，发送成功只表示平台接口接受。

## 命令

`/p站搜图 关键词`、`/p站作者 UID`、`/p站数据 PID`、`/p站发图 PID 页码`。页码从 1 开始；模型工具的内部页索引从 0 开始。

## 画廊

已有 Pixiv 画廊用于搜索、预览与管理；插件卡片的“配置”入口可独立管理全部设置，无需另开页面。
